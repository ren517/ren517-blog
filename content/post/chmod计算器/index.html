命令 效果
chmod u+x file 给 owner 加执行权限
chmod go-w file 去掉 group 和 other 的写权限
chmod a+r file 所有人加读权限
chmod u=rwx,go=rx file 精确设置每组权限
chmod -R 755 /dir/ 递归修改整个目录
chown alice file 改所有者为 alice
chown alice:dev file 改所有者和所属组
u = owner · g = group · o = other · a = all · + 加 · - 去 · = 设为
